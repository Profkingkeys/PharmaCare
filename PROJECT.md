# PharmaCare — Project Case Study

## Overview

PharmaCare is a healthcare-focused frontend project demonstrating product interface design for a pharmacy/medication experience.

## Engineering signal

- responsive browser UI;
- custom CSS design system;
- semantic page structure;
- product-oriented calls to action;
- mobile-conscious layout.

## Stack

HTML5 · CSS3 · JavaScript · Font Awesome

## Why it matters

The project demonstrates the ability to turn a healthcare product concept into a coherent interface without relying on a heavy frontend framework.
